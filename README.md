# LOOM - Custom T-Shirt Design Platform

🌐 **Live Site:** [looom.me](https://looom.me)

## What is LOOM?

LOOM is a web platform where you can design custom t-shirts, hoodies, and other apparel online. Create your unique designs with text, images, and colors, then see them on 3D models before ordering.

## Features

✨ **9 Product Types** - T-shirts, sweatshirts, hoodies, polo shirts, caps, and sweatpants

🎨 **Design Tools**

- Add custom text with different fonts
- Upload your own images (PNG, JPEG, SVG)
- Choose from 5 colors (White, Black, Navy, Gray, Red)
- Adjust size and rotation of your designs

🖥️ **3D Preview** - See your design on interactive 3D models

📱 **Mobile Friendly** - Works on phones, tablets, and computers

## How to Use

1. Browse products on the main page
2. Click "Настроить" (Customize) on any product
3. Add text or upload images
4. Choose colors and adjust your design
5. Preview your creation in 3D

## Technical Details

Built with:

- HTML, CSS, JavaScript
- Tailwind CSS for styling
- Three.js for 3D visualization
- No installation or build tools needed

## Running Locally

```bash
# Clone the repository
git clone https://github.com/TIMURNASRIDDINOV/TIMURNASRIDDINOV.github.io.git
cd TIMURNASRIDDINOV.github.io

# Start a local server (choose one):
python3 -m http.server 8000
# or
php -S localhost:8000
# or
npx serve
```

Open your browser to `http://localhost:8000`
